# My Coaching Manager

My Coaching Manager ek simple aur effective Flutter-based mobile app hai jo teachers aur coaching owners ko apne institute manage karne me madad karta hai. 

## 🎯 App Objective
Yeh app teachers/coaching owners ke liye design kiya gaya hai jisme:
- Students ki fees record aur payment tracking ki ja sakti hai.
- Daily attendance system maintain kiya ja sakta hai.
- Reports aur dashboard views milte hain for better insights.

## 🔑 Core Features
- **👨‍🎓 Student Management**: Students ko add, edit, aur list karne ka feature, jisme name, class, roll no, aur contact details stored hote hain.
- **💰 Fees Management**: Monthly fees tracking, kitni fees collect hui aur kitni pending hai uska record.
- **📅 Attendance Management**: Daily attendance (Present, Absent, Late) mark aur track karne ka system.
- **📊 Dashboard**: Quick stats jaise ki Total Students, Collected Fees, aur Pending Fees ka instant overview.

## ⚙️ Tech Stack
- **Framework**: Flutter
- **Language**: Dart
- **State Management**: Provider-pattern using `ChangeNotifier`
- **Platform Support**: Cross-platform (Android, iOS, Web, Desktop)

## 🚀 Setup & Run
1. Flutter SDK install karein.
2. Repo ko clone karein: `git clone <repository_url>`
3. Dependencies install karein: `flutter pub get`
4. App run karein: `flutter run`
